# План: Скилл и инструмент для работы с Amplicode MCP

## Цель
Создать переиспользуемый скилл и инструмент для взаимодействия с MCP-сервером Amplicode на `http://127.0.0.1:64442/sse`, чтобы не повторять ручную настройку SSE-соединения каждый раз.

## Что создаём

### 1. Скилл `.mimocode/skills/amplicode-mcp/SKILL.md`
Описание:
- Когда использовать (триггеры)
- Какие инструменты доступны через MCP (полный список 51 инструмента)
- Какие инструменты наиболее полезны для проекта Spring Boot
- Примеры использования

### 2. Инструмент `.mimocode/tools/mcp.ts`
Обёртка над MCP-сервером, которая:
- Устанавливает SSE-соединение
- Получает sessionId
- Отправляет JSON-RPC запрос `tools/call`
- Возвращает результат

Аргументы:
- `tool` (string) — имя инструмента MCP (обязательный)
- `arguments` (object, optional) — аргументы для инструмента
- `projectPath` (string, optional) — путь к проекту

## Файлы для создания

| Файл | Назначение |
|------|-----------|
| `.mimocode/skills/amplicode-mcp/SKILL.md` | Скилл с документацией |
| `.mimocode/tools/mcp.ts` | Инструмент-обёртка |

## Реализация инструмента mcp.ts

```ts
import { tool } from "@mimo-ai/plugin"
import { execSync } from "child_process"

export default tool({
  description: "Call an Amplicode MCP tool via SSE. Use for project analysis, build info, Spring beans, endpoints, entities, debugging.",
  args: {
    tool: tool.schema.string().describe("MCP tool name (e.g. list_application_properties_files)"),
    arguments: tool.schema.object({}).optional().describe("Arguments for the MCP tool"),
  },
  async execute(args, ctx) {
    // PowerShell скрипт для SSE + tools/call
    const script = `
      Add-Type -AssemblyName System.Net.Http
      $client = [System.Net.Http.HttpClient]::new()
      $req = [System.Net.Http.HttpRequestMessage]::new([System.Net.Http.HttpMethod]::Get, "http://127.0.0.1:64442/sse")
      $cts = [System.Threading.CancellationTokenSource]::new([TimeSpan]::FromSeconds(20))
      $resp = $client.SendAsync($req, [System.Net.Http.HttpCompletionOption]::ResponseHeadersRead, $cts.Token).GetAwaiter().GetResult()
      $stream = $resp.Content.ReadAsStreamAsync().GetAwaiter().GetResult()
      $reader = [System.IO.StreamReader]::new($stream)
      $buf = New-Object char[] 4096
      $n = $reader.Read($buf, 0, 4096)
      $raw = [string]::new($buf, 0, $n)
      $sid = [regex]::Match($raw, 'sessionId=([a-f0-9\\-]+)').Groups[1].Value
      $body = '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"${args.tool}","arguments":${args.arguments ? JSON.stringify(args.arguments) : "{}"}}}'
      $pc = [System.Net.Http.HttpClient]::new()
      $pr = [System.Net.Http.HttpRequestMessage]::new([System.Net.Http.HttpMethod]::Post, "http://127.0.0.1:64442/message?sessionId=$sid")
      $pr.Content = [System.Net.Http.StringContent]::new($body, [System.Text.Encoding]::UTF8, "application/json")
      $cts2 = [System.Threading.CancellationTokenSource]::new([TimeSpan]::FromSeconds(30))
      $pc.SendAsync($pr, $cts2.Token).GetAwaiter().GetResult() | Out-Null
      Start-Sleep -Seconds 5
      $buf2 = New-Object char[] 65536
      $n2 = $reader.Read($buf2, 0, 65536)
      Write-Output ([string]::new($buf2, 0, $n2))
      $client.Dispose()
      $pc.Dispose()
    `
    // execSync PowerShell, парсим result
  },
})
```
